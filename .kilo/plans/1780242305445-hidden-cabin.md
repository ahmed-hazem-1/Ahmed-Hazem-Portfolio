# Plan: Apply DESIGN.md to Ahmed Hazem Portfolio (React Migration)

## Overview

Convert the current static HTML/CSS/JS portfolio into a **React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + Motion (Framer Motion) v12** project, applying the DESIGN.md design system. Each section will be a separate component file to minimize hallucination risk.

---

## Phase 1: Project Setup

### 1.1 Initialize Vite + React + TypeScript project
- Run `npm create vite@latest` with React+TS template in the same directory (or a `src/` subdirectory)
- Install dependencies: `tailwindcss @tailwindcss/vite motion lucide-react`
- Configure `vite.config.ts` with `@tailwindcss/vite` plugin
- Configure `tsconfig.json`

### 1.2 Configure Tailwind CSS v4
- Create `src/index.css` with Tailwind v4 imports + custom theme tokens
- Define `@theme` block with:
  - `--color-brand-navy: #0B192C`
  - `--color-brand-yellow: #D97706`
  - `--color-brand-gray: #6B7280`
- Add Cairo font via Google Fonts CDN in `index.html`
- Define CSS custom properties from DESIGN.md Section 2 (`:root` block)

### 1.3 Define global CSS classes in `src/index.css`
- `glass-hero`, `glass-navbar`, `glass-card`, `glass-card-dark` (Section 4)
- `fluid-bg-container`, `fluid-blob` (Section 5)
- `gradient-light`, `gradient-navy` (Section 6)
- Keyframe animations: `blob1`, `blob2`, `blob3`, `blob4` (Section 5.4)
- Scroll behavior: `html { scroll-behavior: smooth }`, `body { overflow-x: hidden }`
- Selection styles (Section 17)

## Phase 2: Foundation Components (write one file at a time)

Each file will be written **individually** — no batch writes. This prevents hallucination by keeping context focused.

### 2.1 `src/index.css` — Global styles + Tailwind config
- Tailwind v4 `@import "tailwindcss"` + `@theme` block
- All CSS custom properties from DESIGN.md
- Glassmorphism classes, gradient classes, blob classes, keyframes
- Selection styles, scroll behavior

### 2.2 `src/main.tsx` — React entry point
- Simple React DOM render, import App + index.css

### 2.3 `src/App.tsx` — Root layout
- Composes all section components in order
- Optional: section scroll hook (DESIGN.md Section 13)

### 2.4 `src/components/ui/Button.tsx` — Button component
- Implements DESIGN.md Section 7 (primary/outline/ghost variants, sizes sm/md/lg)
- Uses `motion.button` with `whileTap={{ scale: 0.98 }}`
- Focus ring: `ring-2 ring-brand-yellow ring-offset-2`

### 2.5 `src/components/ui/GlassCard.tsx` — Glass card wrapper
- Props: `variant` (light/dark), `className`
- Applies `glass-card` or `glass-card-dark` + `rounded-2xl` + hover lift

### 2.6 `src/components/ui/TimelineItem.tsx` — Timeline entry
- Used by Experience, Education, Volunteering, Achievements, Certificates
- Glass card style with title, meta, description

### 2.7 `src/components/ui/SkillChip.tsx` — Skill chip
- Badge/pill style on light BG (or muted variant)
- `rounded-full` per DESIGN.md badge pattern

### 2.8 `src/components/ui/ProjectCard.tsx` — Project card
- Glass card with image, overlay, title, tags, description
- Hover lift `-translate-y-1`, filter support

### 2.9 `src/components/ui/SectionHeading.tsx` — Section heading
- `text-3xl md:text-4xl font-bold text-brand-navy leading-tight`

## Key Decisions

- **Project location**: Side-by-side — new Vite project lives in `src/` subdirectory alongside existing static site. Old static files remain until migration is confirmed working.
- **Font**: Cairo (per DESIGN.md) replaces current Poppins
- **Icons**: Lucide React replaces Ionicons (per DESIGN.md)
- **Animations**: Motion (Framer Motion) replaces CSS-only animations
- **Chatbot**: Preserved as React component, same webhook
- **Form**: Same Formspree endpoint
- **Deployment**: Vite build output to `dist/`, update Netlify/Vercel configs
- **Scroll behavior**: Implement section snap scroll per DESIGN.md Section 13 (useSectionScroll hook with 800ms cooldown, keyboard/touch/wheel interception, IntersectionObserver sync)
